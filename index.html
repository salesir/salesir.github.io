◆ Selected Work

Custom Transformer Language Model

Independent Research · Python & PyTorch 2024 — 2026

Built a decoder-only transformer language model from scratch in PyTorch — custom BPE tokenizer, fused QKV attention, RMSNorm and a SwiGLU feed-forward — the modern Llama-style recipe rather than the 2017 paper, with no Hugging Face scaffolding. Trained across 1.5B+ tokens and 383,000+ steps using fp16/bf16 mixed precision, gradient accumulation, and cosine LR scheduling with warmup, driving validation loss from 5.81 down to a 1.2–1.4 band (≈3.4–4.0 perplexity) on held-out batches.

Career Resource Center

Independent · Python, Flask & pywebview 2026

Built a local-first desktop tool that helps job seekers with no technical background write a résumé, track openings, and rehearse interviews. Imports an existing résumé from .docx, .pdf, .txt or .rtf with a three-verdict validator that can answer “unsure” rather than guessing, exports a clean one-page PDF, and runs its assistant through a web-automation bridge so the organisation pays no per-seat API cost. Designed throughout for large type, high contrast, and plain language.

CompanionUni: Desktop Companion

Interactive Systems · Unity 6 URP, C# & Win32 2024 — 2026

Engineered an animated, transparent desktop companion rendered over Windows with alpha-preserving DX11/URP windowing. Reads Explorer’s desktop icons across process boundaries via Win32 virtual memory calls, and executes real file operations through SHFileOperation on a recycle-bin-safe path.
